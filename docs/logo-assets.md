# Logo assets

- `public/logos/apple.svg`: [Simple Icons Apple SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg), provided by Simple Icons under CC0. Original SVG retained.
- `public/logos/android.svg`: [Google Android flat robot SVG](https://developer.android.com/static/images/brand/android-head_flat.svg), under CC BY 3.0. Original SVG retained; attribution appears at the end of the guide.

The guide displays each asset beside its platform heading. Apple uses the inverse color in dark mode for visibility.
