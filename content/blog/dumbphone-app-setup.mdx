## 2. 브라우저 세팅하기: UnTrap · SocialFocus

영상에서  유튜브와 인스타그램을 웹으로 들어가되, 계속 보게 만드는 요소를 확장 프로그램으로 숨기자고 했었죠?

<div className="device-section my-8 rounded-xl border border-border bg-muted/30 p-5 sm:p-6 [overflow-wrap:anywhere] [&>:last-child]:mb-0" data-platform="iphone">

<h3 className="mt-0!"><Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰</h3>

**설치 링크:** [유튜브는 이걸로 UnTrap for YouTube](https://apps.apple.com/us/app/untrap-for-youtube/id1637438059) · [인스타는 이걸로 SocialFocus](https://apps.apple.com/us/app/socialfocus-hide-distractions/id1661093205)

1. 위 링크에서 사용할 앱을 설치합니다.
2. **설정 → 앱 → Safari → 확장 프로그램**으로 들어갑니다.
3. UnTrap과 SocialFocus를 켭니다.
4. 각 확장 프로그램에 필요한 사이트 접근 권한을 허용합니다. Safari에서 사이트를 열었을 때 권한을 묻는 경우에도 허용해주세요.

(옛날 iOS 버전에서는 **설정 → Safari → 확장 프로그램**에 있다고 하네요.)

세부 세팅 알아보시죠:

#### UnTrap 세부 세팅

아래 요소에 해당하는 **Hide / 숨기기** 옵션을 켭니다. 버전과 언어에 따라 메뉴 이름은 조금 다를 수 있습니다.

- **홈 화면의 추천 피드**: 유튜브를 열자마자 뜨는 추천 영상 목록
- **썸네일**: 검색 결과의 썸네일을 포함한 영상 이미지
- **댓글**: 영상 아래 댓글 영역
- **관련 영상 / 추천 영상**: 영상을 보고 있을 때 나오는 다음 영상 목록
- **Shorts**: 쇼츠 목록과 진입 버튼

사실 이건 자기한테 방해되는 것들을 딱 잡아서 끌 수 있다보니까 하나씩 만져보시고 원하시는 세팅을 만드시는 게 베스트긴 합니다.

#### SocialFocus 세부 세팅

- **홈 피드**
- **Reels**
- **추천 게시물 / 추천 콘텐츠**
- 필요하다면 **Stories**도 숨기기

설정 후 Safari에서 사이트를 새로고침해 확인해보세요!

## 3. 흑백 화면으로 만들기

<div className="device-section my-8 rounded-xl border border-border bg-muted/30 p-5 sm:p-6 [overflow-wrap:anywhere] [&>:last-child]:mb-0" data-platform="iphone">

<h3 className="mt-0!"><Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰</h3>

#### 흑백으로 바꾸기

영상에서 흑백으로 폰을 바꾸면 덜 보게 된다고 했었죠. 먼저 평소 화면을 흑백으로 만들어둘게요.

1. 아이폰의 **설정** 앱을 엽니다.
2. **손쉬운 사용 → 디스플레이 및 텍스트 크기 → 색상 필터**로 들어갑니다.
3. **색상 필터** 스위치를 켭니다.
4. 아래 필터 목록에서 **흑백 / 그레이스케일**을 선택합니다. 화면이 흑백으로 바뀌면 완료!

여기서 선택한 흑백 필터를 다음 단축어로 껐다 켜는 거예요. **색상 필터를 끄면 원래 컬러 화면으로 돌아오고, 다시 켜면 흑백이 적용됩니다.**

[Apple 색상 필터 설정 안내](https://support.apple.com/ko-kr/guide/iphone/iph3e2e1fb0/ios)

#### 뒷면 세 번 탭하면 1분 동안 컬러로 바꾸기

평소에는 흑백으로 쓰다가 사진이나 지도를 볼 때 잠깐 컬러가 필요할 수 있잖아요. 그럴 때 아이폰 뒷면을 세 번 두드리면 컬러로 바뀌고, **60초 뒤에 다시 흑백으로 돌아오게** 만드는 겁니다. 컬러로 바꾼 뒤 흑백을 다시 켜는 걸 까먹지 않도록요.

**흑백 → 뒷면 세 번 탭 → 컬러로 60초 사용 → 다시 흑백**

##### 1. ‘1분 컬러’ 단축어 만들기

**단축어**는 여러 동작을 순서대로 실행해주는 아이폰 기본 앱입니다. 여기서는 ‘흑백 끄기 → 60초 기다리기 → 흑백 다시 켜기’를 한 번에 실행하도록 만들 거예요.

1. **단축어** 앱을 열고 **단축어 / 모든 단축어** 화면에서 오른쪽 위 **+** 버튼을 누릅니다.
2. 위쪽의 단축어 이름을 눌러 **이름 변경**을 선택하고, **1분 컬러**라고 입력합니다.
3. **동작 추가** 또는 아래쪽 **동작 검색**에서 **색상 필터**를 검색합니다. **색상 필터 설정** 동작을 추가한 뒤, 동작 안의 **켬 / 끔** 부분을 눌러 **끔**으로 맞춥니다. 이게 컬러 화면으로 바꾸는 첫 번째 동작이에요.
4. 아래쪽 동작 검색에서 **대기**를 검색해서 추가합니다. 동작 안의 초 숫자를 눌러 **60초**로 바꿉니다.
5. 다시 **색상 필터**를 검색해 **색상 필터 설정** 동작을 하나 더 추가합니다. 이번에는 **켬**으로 맞춥니다. 이게 1분 뒤 흑백으로 돌아오는 마지막 동작입니다.
6. 편집기에 위에서부터 **색상 필터 끔 → 대기 60초 → 색상 필터 켬** 순서로 들어가 있는지 확인합니다. 첫 번째와 마지막 동작의 켬 / 끔이 서로 달라야 해요.
7. **완료**를 눌러 저장합니다.

iOS 버전에 따라 버튼 위치나 문구가 조금 다를 수 있어요. 동작이 **전환**으로 표시된다면, 첫 번째는 **끔**, 마지막은 **켬**을 지정하는 방식으로 바꿔주세요.

[Apple 단축어 만들기 안내](https://support.apple.com/ko-kr/guide/shortcuts/apd84c576f8c/ios)

##### 2. 뒷면 삼중 탭에 연결하기

1. **설정 → 손쉬운 사용 → 터치 → 뒷면 탭**으로 들어갑니다.
2. **삼중 탭**을 누릅니다.
3. 목록 아래쪽의 **단축어** 항목에서 방금 만든 **1분 컬러**를 선택합니다.
4. 아이폰 뒷면을 손가락으로 빠르게 **톡톡톡**, 세 번 두드려 실행합니다.

처음에는 화면을 켜둔 상태에서 확인해보세요. **바로 컬러로 바뀌고, 1분 뒤 흑백으로 돌아오면 설정 완료!** 뒷면 탭으로 실행이 안 되면 단축어 앱에서 **1분 컬러**를 직접 눌러 실행해보세요. 단축어 자체가 작동하는지와 뒷면 탭 연결이 됐는지를 따로 확인할 수 있습니다.

뒷면 탭은 **iPhone 8 이후 모델, iOS 14 이상**에서 사용할 수 있습니다. [Apple 뒷면 탭 설정 안내](https://support.apple.com/ko-kr/111772)

#### 흑백으로 바꾸기

제가 안드로이드는 안 쓰고 있어서 찾아보니까 이런 식으로 세팅하면 된다고 합니다. 세팅해보시고 DM 주시면 제가 계속 업데이트 하도록 하겠습니다!

- **갤럭시:** 설정 → 접근성 → 시인성 향상 → 색상 보정 → 사용 → 회색조
- **픽셀:** 설정 → 접근성 → 색상 및 모션 → 색상 보정 → 색상 보정 사용 → 그레이 스케일

기종과 소프트웨어 버전에 따라 메뉴 이름이 다릅니다. 메뉴를 찾기 어렵다면 설정에서 **색상 보정**, **색상 조정**, **회색조**를 검색해보세요

**디지털 웰빙 → 취침 모드 → 화면 옵션 → 그레이 스케일**도 가능합니다. 다만 취침 모드가 켜진 동안에만 흑백을 유지한다고 합니다!

#### 잠깐 컬러로 바꾸기: 세 가지 방법

안드로이드 찾아보니까 세팅 방법이 굉장히 복잡하네요. 가장 쉬운 방법은 바로가기로 직접 전환하는 거고, 1분 뒤 자동으로 흑백에 돌아오게 하려면 추가 앱과 권한 설정이 필요합니다. 아래 세 가지 중에서 골라보세요. 갤럭시에서 삼중 탭을 쓰고 싶다면 세 번째 방법도 참고하시면 됩니다.

##### 1. 쉬운 방법: 바로가기로 수동 전환하기

추가 앱이나 컴퓨터 없이 설정합니다.

1. 위에서 안내한 **색상 보정** 화면을 엽니다.
2. **색상 보정 바로가기**를 켭니다. 기종에 따라 **접근성 바로가기**라는 이름을 사용합니다.
3. 바로가기 버튼이나 설정한 단축 동작으로 색상 보정을 끕니다. 화면이 컬러로 바뀝니다.
4. 컬러를 다 쓰면 같은 바로가기로 색상 보정을 다시 켭니다. 화면이 흑백으로 돌아옵니다.

요 방법으로 했을 때는 1분 후에 자동으로 복귀하지 않고 직접 흑백을 다시 켜야 된다고 합니다.

##### 2. 어려운 방법: Tasker + Tap, Tap으로 1분 동안 컬러로 바꾸기

컬러로 바꾼 뒤 흑백으로 돌아오는 일을 자동화합니다. 추가 앱과 컴퓨터를 통한 최초 권한 설정이 필요합니다.

아이폰이랑 똑같이 하려면 Tasker랑 Tap, Tap을 두 개 깔아야 되네요.

1. 위의 접근성 설정에서 흑백을 켭니다. 취침 모드의 회색조나 개발자 옵션의 흑백 설정은 끕니다.
2. [Tasker](https://play.google.com/store/apps/details?id=net.dinglisch.android.taskerm)를 설치합니다.
3. 컴퓨터에서 [Tasker Permissions](https://github.com/joaomgcd/Tasker-Permissions/releases)를 실행합니다. 안내에 따라 Tasker에 **Write Secure Settings** 권한을 허용합니다. [공식 권한 설정 안내](https://tasker.joaoapps.com/userguide/en/help/ah_secure_setting_grant.html)
4. Tasker의 **Tasks**에서 **1분 컬러**라는 작업을 만듭니다. 아래 동작 3개를 순서대로 추가합니다.

   - **Custom Setting**: Type은 `Secure`, Name은 `accessibility_display_daltonizer_enabled`, Value는 `0`으로 설정합니다. 색상 보정을 끕니다.
   - **Wait**: **60초**로 설정합니다.
   - **Custom Setting**: Type과 Name은 첫 번째 동작과 같습니다. Value는 `1`로 설정합니다. 색상 보정을 다시 켭니다.

5. Tasker의 **Preferences → Misc → Allow External Access**를 켭니다.
6. [Tap, Tap 공식 GitHub](https://github.com/KieronQuinn/TapTap)에서 APK를 설치합니다. 앱의 접근성 권한 안내를 따릅니다.
7. Tap, Tap에서 삼중 탭을 켭니다. 실행 동작에 **Tasker Task → 1분 컬러**를 연결합니다.
8. 먼저 Tasker에서 작업을 직접 실행합니다. 컬러로 바뀐 뒤 60초 후 흑백으로 돌아오는지 확인합니다.
9. 뒷면을 세 번 두드려 같은 동작을 확인합니다.

**Tasker 작업은 성공하지만 삼중 탭을 인식하지 못한다면**, Tap, Tap의 감도를 조절합니다. 앱이 안내하는 배터리 최적화 설정도 확인합니다. Tap, Tap은 가속도 센서와 자이로 센서가 필요합니다.

##### 3. 갤럭시: RegiStar + Tasker로 삼중 탭 연결하기

갤럭시에서는 Tap, Tap 대신 삼성 Good Lock의 **RegiStar**(레지스타)를 사용할 수 있어요. RegiStar는 뒷면을 두 번 또는 세 번 두드렸을 때 지정한 앱을 여는 기능을 제공합니다. [삼성 Members의 RegiStar 사용 예시](https://eu.community.samsung.com/t5/samsung-fun-community/registar-nuevo-m%C3%B3dulo-de-good-lock/td-p/6439090)

여기서는 **RegiStar가 삼중 탭을 감지하고, Tasker가 컬러 전환과 60초 뒤 흑백 복귀를 맡도록** 연결합니다. RegiStar만 설치해서 1분 자동 복귀까지 되는 건 아니고, Tasker 설정은 여전히 필요해요.

**이 방법은 각 앱의 공식 기능을 조합한 것이고, 제가 실제 갤럭시에서 테스트한 방법은 아닙니다.** 기종과 One UI 버전에 따라 지원 여부와 색상 보정 동작이 다를 수 있으니, 아래 순서대로 확인해주세요.

1. **위의 두 번째 방법에서 1~4번까지** 따라 Tasker 설치, 권한 허용, **1분 컬러** 작업 만들기를 완료합니다. Tap, Tap은 설치하지 않아도 됩니다.
2. Tasker에서 **1분 컬러**를 직접 실행해 **컬러 전환 → 60초 뒤 흑백 복귀**가 되는지 먼저 확인합니다. 이 단계에서 안 되면 RegiStar를 연결해도 해결되지 않으니, Tasker 권한과 해당 기기의 색상 보정 설정부터 확인해주세요.
3. Tasker의 **Preferences**(환경설정)에서 **Secondary App / Secondary App Enabled** 항목을 켭니다. 앱 목록에 **Tasker Secondary**가 표시되도록 하는 설정입니다. Tasker Secondary는 지정한 작업을 실행하기 위한 별도 아이콘이에요.
4. Tasker의 **Profiles → + → Event**(이벤트)에서 **Secondary App Opened**를 검색해 선택합니다. 뒤로 돌아가 실행할 작업으로 **1분 컬러**를 연결하고, 변경 사항을 저장·적용합니다. [Tasker 공식 이벤트 설명](https://tasker.joaoapps.com/userguide/en/help/eh_secondary_app_opened.html)
5. 앱 목록에서 **Tasker Secondary**를 직접 열어 같은 작업이 실행되는지 확인합니다.
6. Galaxy Store에서 **Good Lock**을 설치하고, Good Lock 안에서 **RegiStar**를 찾아 설치합니다. [RegiStar 설치 링크](https://galaxystore.samsung.com/detail/com.samsung.android.app.galaxyregistry)
7. RegiStar의 **Back-Tap action**(뒷면 두드리기 액션)을 켭니다. **Triple Tap → Open app**(세 번 두드리기 → 앱 실행)에서 **Tasker Secondary**를 선택합니다.
8. 화면을 켜둔 상태에서 뒷면을 빠르게 세 번 두드려 확인합니다. 컬러로 바뀐 뒤 60초 후 흑백으로 돌아오는지 확인해주세요.

**Tasker Secondary를 직접 열면 되는데 삼중 탭으로는 안 된다면**, RegiStar의 뒷면 두드리기 설정과 감도를 확인합니다. RegiStar에 해당 메뉴가 없거나 기기에서 지원하지 않는다면 첫 번째 방법으로 수동 전환하거나 두 번째 방법을 검토해주세요.

이거 혹시 조금 더 쉽게 세팅할 수 있는 방법 아시는 분 있으면 DM 보내주세요. 같이 나눕시다.

## 5. 홈 화면 성형수술

<div className="device-section my-8 rounded-xl border border-border bg-muted/30 p-5 sm:p-6 [overflow-wrap:anywhere] [&>:last-child]:mb-0" data-platform="iphone">

**Dumbify 또는 Dumb Phone**

둘 중 하나만 설치하면 됩니다. 저는 일회성 결제라서 dumbify 씀. 근데 살짝 ux 안좋아요.

- [Dumbify](https://apps.apple.com/us/app/dumbify/id6480082872): 유료 앱
- [Dumb Phone](https://dumbphone.so/): 무료 다운로드 후 체험·유료 업그레이드 방식

설정 순서는 다음과 같습니다.

1. 앱 설치하고 
2. 앱에서 시키는 대로 온보딩 마칩니다 (여기서 보일 앱들을 리스트에 추가하는 거랑, 배경 바꾸는 거 해요) 그리고
3. dumbify (아니면 dumb phone) 위젯을 추가해요
4. 기존 앱 아이콘들은 다 지워요. (안 쓰는 홈 화면 페이지는 체크 해제해서 안 보이게 하세요)

#### 무료 대안: Minimalist Launcher

**@gahyeoff** 님이 댓글로 아이폰에서 무료로 시작할 수 있는 **Minimalist Launcher**를 알려주셨어요. 덕분에 무료 대안도 추가합니다. 감사합니다, 샤라웃!

[Minimalist Launcher 아이폰 설치](https://apps.apple.com/kr/app/minimalist-launcher/id6498880303) · [공식 안내](https://www.minimalistlauncher.app/)

필요한 앱을 간단한 글자 목록으로 보여주는 홈 화면을 만들 수 있어요. **기본 기능은 무료**이고, 배경·테마·추가 꾸미기 옵션에는 유료 업그레이드가 있습니다.

1. 앱을 설치하고, 안내에 따라 홈 화면에 둘 필수 앱을 고릅니다.
2. 앱의 설정 안내를 따라 **Minimalist Launcher 위젯**을 홈 화면에 추가합니다.
3. 위젯과 어울리는 배경을 설정하고, 기존 앱 아이콘은 홈 화면에서 제거하거나 다른 페이지로 옮깁니다. 앱 자체를 삭제할 필요는 없어요.
4. 위젯의 앱 이름을 눌러 원하는 앱이 열리는지 확인합니다.

유료 앱을 결제하기 전에 이런 홈 화면이 나한테 맞는지 먼저 써보고 싶은 분들께 좋은 선택지네요!
