## 2. 브라우저 세팅하기: UnTrap · SocialFocus

유튜브와 인스타그램을 웹으로 들어가되, 계속 보게 만드는 요소를 확장 프로그램으로 숨깁니다.

### <Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰

**설치 링크:** [UnTrap for YouTube](https://apps.apple.com/us/app/untrap-for-youtube/id1637438059) · [SocialFocus](https://apps.apple.com/us/app/socialfocus-hide-distractions/id1661093205)

1. 위 링크에서 사용할 앱을 설치합니다.
2. **설정 → 앱 → Safari → 확장 프로그램**으로 들어갑니다.
3. UnTrap과 SocialFocus를 켭니다.
4. 각 확장 프로그램에 필요한 사이트 접근 권한을 허용합니다. Safari에서 사이트를 열었을 때 권한을 묻는 경우에도 허용해주세요.
5. UnTrap·SocialFocus 앱이나 Safari의 확장 프로그램 메뉴에서 아래 숨김 옵션을 설정합니다.

이전 iOS에서는 **설정 → Safari → 확장 프로그램**에 있습니다. [Apple 설정 안내](https://support.apple.com/ko-kr/guide/iphone/iphab0432bf6/ios)

#### UnTrap: 이 항목들을 숨기기

아래 요소에 해당하는 **Hide / 숨기기** 옵션을 켭니다. 버전과 언어에 따라 메뉴 이름은 조금 다를 수 있습니다.

- **홈 화면의 추천 피드**: 유튜브를 열자마자 뜨는 추천 영상 목록
- **썸네일**: 검색 결과의 썸네일을 포함한 영상 이미지
- **댓글**: 영상 아래 댓글 영역
- **관련 영상 / 추천 영상**: 영상을 보고 있을 때 나오는 다음 영상 목록
- **Shorts**: 쇼츠 목록과 진입 요소

#### SocialFocus: 인스타그램에서 이 항목들을 숨기기

- **홈 피드**
- **Reels**
- **추천 게시물 / 추천 콘텐츠**
- 필요하다면 **Stories**도 숨기기

설정 후 Safari에서 사이트를 새로고침해 확인합니다. 이 설정은 **브라우저에서 보는 웹사이트**에 적용됩니다.

**비용:** 아이폰용 UnTrap과 SocialFocus는 유료 앱입니다.

### <Image src="/logos/android.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle" /> 안드로이드

**설치 링크:** [UnTrap for YouTube](https://addons.mozilla.org/en-US/firefox/addon/untrap-for-youtube/) · [SocialFocus](https://addons.mozilla.org/en-US/firefox/addon/socialfocus/)

1. Firefox를 설치하고, **Firefox 안에서** 위 설치 링크를 엽니다.
2. **Firefox에 추가**를 눌러 설치하고 필요한 권한을 허용합니다.
3. Firefox 메뉴의 **확장 기능 / Extensions**에서 설치한 확장 프로그램을 엽니다.
4. 설정으로 들어가 아래 숨김 옵션을 켭니다.

[Firefox Android 확장 기능 설치 안내](https://support.mozilla.org/en-US/kb/find-and-install-add-ons-firefox-android)

## 3. 흑백 화면으로 만들기

### <Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰

#### 흑백으로 바꾸기

**설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 색상 필터 → 켬 → 흑백**

[Apple 색상 필터 안내](https://support.apple.com/ko-kr/111773)

#### 뒷면 세 번 탭하면 1분 동안 컬러로 바꾸기

영상의 세팅은 평소에는 흑백이고, 뒷면을 세 번 두드리면 잠깐 컬러로 바뀌는 방식입니다.

단축어 앱에서 새 단축어를 만들고, 다음 동작을 순서대로 넣습니다.

1. **색상 필터 설정 → 끔**
2. **대기 → 60초**
3. **색상 필터 설정 → 켬**

이름을 **1분 컬러**로 저장한 뒤, **설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → 삼중 탭**에서 이 단축어를 선택합니다.

뒷면 탭에 ‘색상 필터’를 바로 연결하면 수동으로 켜고 끄게 됩니다. 1분 뒤 돌아오게 하려면 위처럼 단축어를 연결해야 합니다. [Apple 뒷면 탭 안내](https://support.apple.com/ko-kr/111772)

> **초안 확인 항목:** 위 단축어는 영상의 동작을 구현하기 위한 구성안입니다. 실제 사용한 단축어와 대조하고, 화면이 잠긴 상태에서도 60초 뒤 흑백으로 복귀하는지 기기에서 확인해야 합니다.

### <Image src="/logos/android.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle" /> 안드로이드

설정에서 **회색조** 또는 **그레이스케일**을 검색합니다. 지원되는 기기는 **디지털 웰빙 → 취침 모드 → 화면 옵션**에서도 회색조를 켤 수 있습니다. 취침 모드에 연결한 경우에는 해당 모드가 켜져 있을 때 적용됩니다.

기종에 따라 메뉴 위치가 다릅니다. [Google 디지털 웰빙 안내](https://support.google.com/android/answer/9346420?hl=ko)

## 4. 앱을 열기 전에 잠깐 멈추기: one sec

자꾸 열게 되는 앱을 지정하면, 앱이 열리기 전에 짧은 호흡 화면을 보여줍니다.

### <Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰

[one sec 설치](https://one-sec.app/)

1. one sec에서 개입을 적용할 앱을 추가합니다.
2. 앱이 안내하는 **단축어 자동화 설정**을 완료합니다.
3. 수동으로 설정해야 한다면 **단축어 → 자동화 → 앱**에서 대상 앱을 선택합니다.
4. 조건은 **열릴 때**, 실행 방식은 **즉시 실행**으로 선택합니다.
5. 동작에 **Activate one sec**를 추가하고, one sec에 등록한 대상 앱을 지정합니다.
6. 해당 앱을 직접 열어 호흡 화면이 나오는지 확인합니다.

iOS와 one sec 버전에 따라 앱 안에서 자동화를 가져오는 방식으로 안내될 수 있습니다. 화면에 표시되는 설치 절차를 따라주세요. [아이폰 공식 설정 안내](https://tutorials.one-sec.app/en/articles/3034626)

#### 대기 시간을 짧게 맞추기

one sec의 **Settings → Interventions → 해당 개입 → Customize**에서 시간을 조절합니다.

영상처럼 짧게 멈추는 방식으로 시작하고, **3초 옵션이 표시된다면** 선택해주세요.

설정 가능한 시간과 커스텀 기능은 버전·요금제에 따라 다릅니다. [개입 커스텀 안내](https://tutorials.one-sec.app/en/articles/3310978)

**무료 범위:** 기본 호흡 개입을 앱 1개에 적용할 수 있습니다. 여러 앱에 적용하거나 추가 기능을 쓰려면 유료 버전이 필요합니다. [one sec FAQ](https://one-sec.app/faq/)

### <Image src="/logos/android.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle" /> 안드로이드

[one sec 설치](https://one-sec.app/)

1. one sec에서 대상 앱을 추가합니다.
2. 앱이 요청하는 **접근성 권한**과 **다른 앱 위에 표시** 권한 등을 설정합니다.
3. 기기에 따라 사용 정보 접근 등 추가 안내가 나오면 완료합니다.
4. 대상 앱을 열어 개입 화면이 나오는지 확인합니다.

[안드로이드 공식 설정 안내](https://tutorials.one-sec.app/en/articles/3034754)

#### 대기 시간을 짧게 맞추기

one sec 설정의 개입 관련 메뉴에서 시간을 조절합니다.

영상처럼 짧게 멈추는 방식으로 시작하고, **3초 옵션이 표시된다면** 선택해주세요.

설정 가능한 시간과 커스텀 기능은 버전·요금제에 따라 다릅니다. [개입 커스텀 안내](https://tutorials.one-sec.app/en/articles/3310978)

**무료 범위:** 기본 호흡 개입을 앱 1개에 적용할 수 있습니다. 여러 앱에 적용하거나 추가 기능을 쓰려면 유료 버전이 필요합니다. [one sec FAQ](https://one-sec.app/faq/)

## 5. 홈 화면 성형수술

### <Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰

**Dumbify 또는 Dumb Phone**

둘 중 하나만 설치하면 됩니다.

- [Dumbify](https://apps.apple.com/us/app/dumbify/id6480082872): 유료 앱
- [Dumb Phone](https://dumbphone.so/): 무료 다운로드 후 체험·유료 업그레이드 방식

설정 순서는 다음과 같습니다.

1. 앱을 열고 홈 화면에 남길 필수 앱을 고릅니다.
2. 홈 화면 빈 공간을 길게 눌러 **편집 → 위젯 추가**로 들어갑니다.
3. 설치한 앱의 위젯을 선택해 추가합니다. Dumb Phone은 앱 안의 **Page 1 → Add Widget** 안내도 이용할 수 있습니다.
4. 기존 앱 아이콘은 길게 눌러 **앱 제거 → 홈 화면에서 제거**합니다.
5. 나머지 홈 화면 페이지는 **편집 → 페이지 편집**에서 체크를 해제합니다.
6. 단색 배경화면을 쓰고 위젯 배경색을 맞춰 정리합니다.

[Dumb Phone 위젯 추가 안내](https://help.dumbphone.so/article/20-set-up-guide-add-widget) · [미니멀 홈 화면 설정 안내](https://help.dumbphone.so/article/24-set-up-guide-create-minimalist-home-screen)

### <Image src="/logos/android.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle" /> 안드로이드

**Olauncher**

[Olauncher 설치](https://play.google.com/store/apps/details?id=app.olauncher)

1. 설치 후 Olauncher를 **기본 홈 앱 / 기본 런처**로 선택합니다.
2. 홈 화면에 표시할 앱을 눌러 필수 앱으로 바꿉니다.
3. 홈 화면 빈 공간을 길게 눌러 설정으로 들어갑니다.
4. 표시할 앱 수, 글자 크기와 정렬을 원하는 대로 조절합니다.
5. 단순한 배경화면을 설정합니다.

**비용:** 무료이며 광고가 없습니다. [Olauncher 공식 프로젝트](https://github.com/tanujnotes/Olauncher)

## 6. 사용할 시간을 정해두기: Opal

### <Image src="/logos/apple.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle dark:invert" /> 아이폰

[Opal 설치](https://opalapp.com/)

1. 설치 후 차단에 필요한 권한을 설정합니다.
2. **Blocks → + New Block → Create Schedule**로 들어갑니다.
3. 차단 시작·종료 시간과 반복할 요일을 고릅니다.
4. 차단할 앱을 선택합니다. 웹으로 이용한다면 유튜브·인스타그램의 웹사이트도 차단 대상에 추가합니다.
5. 저장하고 일정을 활성화합니다.

예를 들어 **매일 오후 8시부터 다음 날 오전 1시까지** 차단하도록 설정할 수 있습니다. 허용할 시간을 남기고, 나머지 시간대를 차단하는 방식으로 맞추면 됩니다.

[Opal 일정 설정 안내](https://opalapp.com/help/what-are-sessions)

**무료 범위:** 공식 요금 안내에서는 반복 세션 3개를 무료로 제공합니다. 무제한 반복 세션과 일부 강한 차단 기능은 Pro에 포함됩니다. 실제 기기의 요금제 화면에서 적용 범위를 확인해주세요. [Opal 무료·유료 기능 안내](https://opalapp.com/help/why-pay-for-opal)

### <Image src="/logos/android.svg" alt="" width={24} height={24} className="my-0! mr-2! inline-block h-6 w-6 object-contain align-middle" /> 안드로이드

[Opal 설치](https://opalapp.com/)

1. 설치 후 차단에 필요한 권한을 설정합니다.
2. **Home → + New Block → Create Schedule**로 들어갑니다.
3. 차단 시작·종료 시간과 반복할 요일을 고릅니다.
4. 차단할 앱을 선택합니다. 웹으로 이용한다면 유튜브·인스타그램의 웹사이트도 차단 대상에 추가합니다.
5. 저장하고 일정을 활성화합니다. **Start Schedule**이 보이면 눌러 시작합니다.

예를 들어 **매일 오후 8시부터 다음 날 오전 1시까지** 차단하도록 설정할 수 있습니다. 허용할 시간을 남기고, 나머지 시간대를 차단하는 방식으로 맞추면 됩니다.

아이폰과 메뉴·제공 기능이 조금 다를 수 있습니다. [Opal 안드로이드 안내](https://opalapp.com/help/introducing-opal-for-android)
